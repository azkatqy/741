Menjalankan prototipe

Prototipe terdiri atas server, aplikasi penumpang, halaman monitor, dan simulator kendaraan. Simulator menggantikan node penghubung dan node deteksi ROS 2 dengan protokol WebSocket yang sama, sehingga seluruh alur bisa dicoba tanpa mobil riset.

Prasyarat Konfigurasi Menjalankan Skenario demo Parameter Tes otomatis Masalah umum

Kode prototipe disimpan di repositori terpisah. Halaman ini hanya berisi petunjuk penggunaannya.

Prasyarat

  • Python 3.10 atau lebih baru.
  • Kunci API Google Gemini atau OpenRouter untuk agen percakapan dan VLM.
  • Opsional: GPU yang didukung PyTorch. Tanpa GPU, YOLO-World berjalan di CPU sekitar 0,1 detik per frame.
cd robotaxi
pip install --user -r requirements.txt

Konfigurasi

Salin .env.example menjadi .env di folder robotaxi/, lalu isi kunci API. Berkas .env diabaikan oleh git, jadi jangan pernah menyalin kunci ke berkas lain yang ikut di-commit.

VariabelFungsi
LLM_PROVIDERgoogle (Gemini API langsung) atau openrouter
GOOGLE_API_KEYKunci Gemini API, dipakai bila penyedia google
OPENROUTER_API_KEYKunci OpenRouter, dipakai bila penyedia openrouter
GEMINI_CHAT_MODEL, GEMINI_VLM_MODELNama model, misalnya gemini-3.1-flash-lite. Untuk OpenRouter otomatis diberi awalan google/
VEHICLE_TOKENToken yang dipakai kendaraan atau simulator untuk tersambung ke server

Penyedia dan model juga bisa diganti saat aplikasi berjalan lewat ikon pengaturan di halaman simulator. Model yang dipakai dicatat di setiap hasil identifikasi.

Skenario demo

  1. Siapkan kamera simulator.Tarik video atau foto ke slot kamera kiri, tengah, atau kanan, atau pilih "Pakai contoh…".
  2. Pesan dari aplikasi penumpang.Pilih titik jemput, tekan "Pesan Robotaxi", lalu ceritakan ciri Anda di tab Percakapan, misalnya pakaian atas beserta warnanya dan posisi Anda.
  3. Percepat perjalanan.Di simulator, naikkan kecepatan atau tekan "Langsung tiba".
  4. Kendaraan tiba.Bila ciri belum lengkap, status menjadi menunggu ciri dan VLM belum dipanggil. Bila sudah lengkap, status menjadi mencari dan VLM diperiksa setiap 3 detik.
  5. Periksa foto bukti.Bila VLM menemukan kandidat, foto dengan kotak hijau dikirim ke percakapan. Jawab "Ya, itu saya" untuk mengonfirmasi atau "Bukan saya" agar agen menanyakan ciri pembeda.
  6. Selesaikan.Setelah naik, tekan "Saya sudah di kendaraan". Pesanan ditutup dan deteksi dihentikan.

Untuk menguji jalur cadangan, tekan "Minta foto kamera" setelah kendaraan tiba, lalu pilih nomor diri Anda pada foto. Untuk menguji status OFFLINE, tekan "Putuskan koneksi" di simulator.

Tes otomatis

cd server
python3 -m pytest -q tests

Tes mencakup transisi status, penyaring halusinasi, aturan kelengkapan ciri, penggabungan panel kamera, logika keputusan VLM, batas waktu, dan alur lengkap dengan model serta kendaraan tiruan.

Masalah umum

"Maaf, saya sedang kesulitan memproses pesan Anda"

Panggilan ke LLM gagal. Periksa apakah kunci API sudah diisi, penyedianya sesuai LLM_PROVIDER, dan nama modelnya tersedia. Baris kosong seperti GOOGLE_API_KEY= diabaikan, jadi isi nilainya atau hapus barisnya.

VLM tidak pernah dipanggil

Biasanya ciri belum lengkap, sehingga status tertahan di menunggu ciri. Pastikan pakaian atas beserta warnanya dan posisi sudah disebut. Lihat juga Log VLM di simulator.

Peta tidak tampil

Aplikasi memakai ubin OpenStreetMap. Pastikan peramban bisa mengakses internet.

Titik jemput lama masih muncul

Hapus server/data/robotaxi.db lalu jalankan ulang agar seed.json dimuat ulang.
