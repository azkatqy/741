# Robotaxi ITS: Halaman Pendukung Tugas Akhir

Situs statis untuk Tugas Akhir **Sistem Layanan Penjemputan Robotaxi dengan Validasi Identifikasi Penumpang Berbasis Vision-Language Model** (Departemen Teknik Komputer ITS).

| Halaman | Isi |
|---|---|
| `index.html` | Ringkasan, ilustrasi alur penjemputan, ruang lingkup, hasil awal |
| `materi.html` | Penjelasan metode, algoritma, alat, teori, dan latihan pertanyaan sidang |
| `sistem.html` | Arsitektur, alur 19 langkah, status pesanan, integrasi navigasi, basis data |
| `petunjuk.html` | Menjalankan prototipe, skenario demo, parameter, masalah umum |
| `pedoman.html` | Ciri penumpang, titik jemput, pengujian, privasi, penulisan proposal, istilah |
| `referensi.html` | Daftar pustaka dengan tautan DOI/arXiv/kode dan dokumentasi alat |
| `galeri.html` | Tangkapan layar aplikasi penumpang dan simulator |

Tanpa proses build. Buka `index.html` langsung, atau aktifkan GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.
